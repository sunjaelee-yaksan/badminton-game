# 🏸 배드민턴 클래스 — 1단계 프로토타입

계정 없이 브라우저에서 바로 하는 **배드민턴 수업용 게임**입니다.
- 단식(나 vs AI), 복식(나 + AI 파트너 vs AI 2명)
- **온라인 대전**: 계정 없이 방 코드로 최대 4명(2:2), 빈 자리는 AI
- 튜토리얼 7개: 0 키 조작 → 1 빨간 원 → 2 클리어·스매시·드롭 → 3 네트 → 4 백핸드 → 5 서브 규칙·높이 → 6 복식 규칙
PC(키보드)와 태블릿·스마트폰(가상 조이패드)에서 모두 동작합니다.

---

## 1. 처음 한 번만: 준비

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전 설치 (설치 후 컴퓨터 재시작 권장)
2. 이 폴더(`badminton-class-game`)를 원하는 곳에 압축 해제
3. 폴더에서 터미널 열기
   - Windows: 폴더 빈 곳에서 `Shift + 마우스 오른쪽` → "터미널에서 열기"(또는 PowerShell)
   - VS Code를 쓰면: 폴더 열기 → 메뉴 `터미널 > 새 터미널`
4. 아래 명령 입력 (필요한 부품 설치, 1~2분)
   ```
   npm install
   ```

## 2. 내 컴퓨터에서 실행

```
npm run dev
```
화면에 나오는 주소 중 `Local: http://localhost:5173` 을 크롬에서 엽니다.
코드를 고치고 저장하면 화면이 자동으로 새로고침됩니다.

**같은 와이파이의 태블릿·폰에서 해보기**: 같은 화면에 나오는 `Network: http://192.168.x.x:5173` 주소를 태블릿 크롬에 입력하세요.
(학교망은 기기 간 접속이 막혀 있을 수 있습니다. 그럴 땐 아래 3번 배포 방법을 쓰세요.)

끝낼 때는 터미널에서 `Ctrl + C`.

## 3. 학생들에게 나눠주기

### 방법 A. 인터넷 주소로 배포 (추천 · 무료)
1. GitHub에 이 폴더를 저장소로 올리기 (`node_modules`, `dist` 폴더는 제외 — `.gitignore`에 이미 설정됨)
2. https://vercel.com 로그인 → **Add New → Project** → 방금 만든 저장소 선택
3. Framework Preset이 **Vite**로 자동 선택되는지 확인 → **Deploy**
4. 생기는 주소(`https://○○○.vercel.app`)를 학생들에게 공유 — QR코드로 만들어 칠판에 띄우면 편합니다
5. 이후 GitHub에 코드를 올릴 때마다 자동으로 다시 배포됩니다

### 방법 B. 파일 하나로 만들기
```
npm run build:single
```
`dist-single/index.html` 파일 하나에 게임 전체가 들어갑니다. 크롬으로 열면 바로 실행되므로 USB나 메신저로 전달할 수 있습니다.

## 4. 자동 점검 (코드를 고친 뒤 확인용)

npm run test:tutorial    # 튜토리얼 공 받기·서브 단계가 모두 달성 가능한지

## 6. 조작 규칙 (v0.2)

- **이동**: 8방향, 몸 방향은 자동 전환
- **대시**: Space(또는 Shift) — 또는 같은 방향키 빠르게 두 번. 방향키를 누른 상태여야 함, 스태미나 사용
- **클리어 버튼(J)**: 뒤에서 클리어 · 네트 앞 높은 공은 푸시 · 낮은 공은 리프트
- **헤어핀 버튼(K)**: 네트 앞 = 헤어핀, 뒤쪽 = 드롭
- **백핸드 버튼(L)**: 위치에 따라 백핸드 클리어/드롭/헤어핀/리프트
- **스매시 = J+K 동시**, **백핸드 스매시 = L+K 동시** (첫 입력에 스윙 시작, 0.1초 안에 두 번째 버튼이 오면 스매시)
  - 타이밍: 빠르면 네트 / 정확하면 스매시 / 늦으면 드라이브
- **서브 흐름**
  1. 서브 차례가 되면 **3초 카운트다운** — 서버는 초록 칸, 리시버는 파란 칸으로 **직접 걸어감** (나머지 선수는 자유)
  2. 서버·리시버가 칸 안에 들어가야 서브 시작 (안 들어가면 안내가 뜨고 기다림) → 둘 다 움직일 수 없음
  3. 내가 서버면 **1인칭 시점**: ↑↓ = 타점 높이(오른쪽 게이지), ←→ = 방향, J = 롱서브 / K·L = 숏서브
  4. 타점이 **1.15m보다 높으면 서브 폴트** (빨간 선으로 표시)
- **복식 서브 로테이션**(자동 적용 + 화면 설명)
  - 서브 팀 점수 짝수 → 오른쪽, 홀수 → 왼쪽 코트에 서 있는 사람이 서브
  - 서브 팀이 이기면: 같은 서버가 계속, 서버 팀 두 사람이 좌우 자리 바꿈
  - 리시브 팀이 이기면: 서브권 이동, 자리는 그대로
- **표시**: 그림자 = 떨어질 곳 · 빨간 원 = 서야 할 곳 · 하얀 원이 빨간 원과 겹칠 때 누르기
  - 복식에서 파트너가 받을 공이면 그림자만 보임

## 8. 온라인 대전 (P2P, 계정 없이 방 코드)

**사용법**
1. 방장(교사 또는 학생 1명): 메뉴 → `온라인 대전` → 닉네임 → 복식/단식 선택 → `방 만들기` → 4자리 코드가 나옴
2. 참가자(최대 3명): 같은 주소로 접속 → `온라인 대전` → 닉네임 + 코드 → `참가`
3. 방장이 `경기 시작` → 빈 자리는 AI가 채움. 참가 순서: 2번째 사람은 상대 팀(B팀), 3번째는 방장 파트너, 4번째는 B팀
4. 경기가 끝나면 방장이 `대기실로` → 다시 `경기 시작`

**동작 방식**
- 방장 브라우저가 경기를 계산하고(`src/core` 그대로), 참가자는 이동·버튼 입력만 보냄
- 방장이 초당 30번 화면 상태를 보냄 → 참가자는 셔틀을 물리로 이어 그리고, 자기 선수는 먼저 움직여서 반응 지연을 줄임
- 참가자 화면은 자기 코트가 아래로 오도록 카메라·미니맵·점수판이 뒤집힘 (우리 팀은 항상 파랑)
- 참가자가 나가거나 4초 이상 입력이 없으면 그 자리는 AI가 이어서 함 / 방장이 나가면 참가자에게 안내 후 메뉴로
- 개인정보: 닉네임만 주고받고 저장하지 않음(닉네임은 각자 브라우저에만 저장)

**주의**
- Claude에서 공유한 미리보기 링크에서는 보안 제한 때문에 온라인 대전이 안 됩니다. **Vercel로 배포한 주소**나 `npm run dev`, `dist-single/index.html` 파일로 실행하세요.
- 처음 연결만 PeerJS 공개 연결 서버(0.peerjs.com)를 거치고, 연결 후 경기 데이터는 기기끼리 직접 오갑니다.
- **학교 와이파이에서 연결이 안 될 때**: ① 휴대폰 핫스팟으로 시험 ② 학교 정보부/교육청에 WebRTC·peerjs.com 허용 문의 ③ 자체 연결 서버 사용 — `npm run peer-server`(이 컴퓨터가 서버) 후 주소 뒤에 `?peerhost=서버IP&peerport=9000` (설정 위치: `src/config/network.js`)
- 그래도 막히는 학교망이 많다면 다음 단계에서 '중계 서버' 방식으로 바꾸면 됩니다(게임 코드는 그대로, `src/net/room.js`만 교체).

**시험해 보는 법 (컴퓨터 한 대로)**: `npm run peer-server`와 `npm run dev`를 각각 실행 → 크롬 창 2개(하나는 시크릿 창)에서 `http://localhost:5173/?peerhost=localhost&peerport=9000` 접속 → 한쪽은 방 만들기, 다른 쪽은 참가
